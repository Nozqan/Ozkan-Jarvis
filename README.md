# AKREP JARVIS - OMNIPOTENT OFFLINE & ONLINE AI ASSISTANT

**Geliştirici:** Nebi Özkan | Marka: AKREP  
**Platform:** Android (Kotlin + Jetpack Compose)  
**Sürüm:** 4.9  
**Motor:** Qwen 2.5 1.5B Instruct GGUF & Google Gemini API Integration  

---

## Proje Vizyonu ve Kimliği
AKREP JARVIS, telefonun donanımını (kamera, fener, Wi-Fi, Bluetooth, ses, aramalar, SMS) sesli komutlarla doğrudan yönetebilen, arka planda sürekli dinlemede kalabilen (Wake Word & Foreground Service), cyberpunk estetiğine sahip üst düzey bir Android asistanıdır.

## Temel Özellikler
1. **3D Dinamik Arayüz:** Derin uzay siyahı arka plan, parıldayan güneş ve yıldız silüetleri, neon sarı, kırmızı ve yeşil ses dalgası animasyonları.
2. **Kapsamlı Komut Yönetimi:** 250+ yerel ve yapay zeka destekli sesli komut işleyicisi (Fener, Kamera, Medya Kontrolü, Wi-Fi, Pil durumu, vb.).
3. **API ve Model Entegrasyonu:** Google Gemini API ve OpenAI API anahtarları ile esnek çevrimiçi mod, ayrıca Qwen 2.5 model indirme desteği.
4. **Çevrimiçi TTS Profilleri:** Kalın Erkek Ses (Jarvis), Olgun Erkek Ses ve Bayan ses seçenekleri.
5. **Mutlak İzin Yönetimi:** Arka plan mikrofon servisi, kilit ekranı üzerinden uyandırma, overlay ve donanım kontrolü.
